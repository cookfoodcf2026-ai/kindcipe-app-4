❓ 常見問題

點樣取消訂閱？

iOS：設定 → Apple ID → 訂閱 → Kindcipe → 取消。
Android：Google Play → 訂閱 → Kindcipe → 取消。

點樣刪除帳戶？

App 內：設定 → 刪除帳戶。所有個人資料會被移除，此操作不可復原。

AI 生成唔到食譜？

請確認網絡連線正常，或稍後再試。免費版每月有使用上限。

買餸清單點樣分享？

購物清單頁 → 一鍵導出／分享，即可 Send 畀家人或姐姐。

支援邊幾種語言？

繁體中文、English、Filipino（Tagalog）、Bahasa Indonesia。可在「設定 → 顯示語言」切換。

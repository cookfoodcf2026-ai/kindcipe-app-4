20 分鐘 · 中等 · 川菜

麻婆豆腐

麻辣鮮香，送飯一流嘅川菜經典。

食材

  • 嫩豆腐 1 盒
  • 免治豬肉 100 克
  • 豆瓣醬 1 湯匙
  • 花椒粉 少許
  • 蒜蓉 1 茶匙
  • 蔥花 適量

步驟

  1. 豆腐切粒，汆鹽水備用。
  2. 炒香豬肉，加豆瓣醬同蒜蓉。
  3. 加水煮滾，落豆腐輕推。
  4. 煮 3 分鐘，勾薄芡。
  5. 灑花椒粉同蔥花即可。

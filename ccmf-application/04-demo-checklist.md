# Kindcipe CCMF Demo 準備清單

> 目標：確保 CCMF 面試時有流暢、impressive 嘅實機 Demo
> 建議準備時間：2027-11 底前完成所有準備

## 1. Demo 腳本（5–7 分鐘）

### 開場（30 秒）
> 「大家好，我係 Mavis。今日向大家介紹 Kindcipe——一個專為香港家庭打造嘅廣東話 AI 食譜平台。我哋相信：當所有人都話手機有害，我哋可以因為手機，連結起來，共聚晚餐。」

### 場景一：IG 食譜匯入（1 分鐘）
**演示流程**：
1. 打開 App，點擊中央「+」按鈕
2. 剪貼板自動偵測到 IG 連結（預先複製好的食譜連結）
3. 點擊「立即解析」
4. AI 正在解析食譜（展示 loading 動畫）
5. 解析成功，顯示食譜名稱、食材、步驟預覽
6. 點擊「儲存到食譜庫」

**預先準備**：
- 剪貼板預先放入 2–3 個已知可成功解析的 IG 食譜連結
- 準備截圖後備（如果現場網絡不穩）

### 場景二：AI 廣東話排餐（1 分鐘）
**演示流程**：
1. 進入排餐頁面
2. 點擊某天某餐（例如「星期三晚餐」）
3. 選擇「新增」，進入食譜庫
4. 點擊剛匯入的食譜
5. 展示食材勾選、步驟瀏覽
6. 進入烹飪模式，展示計時器和步驟導航

**預先準備**：
- 排餐頁面預先排好 2–3 天的餐
- 食譜庫有 5–10 個已匯入的食譜

### 場景三：家庭共享 + 工人模式（1.5 分鐘）
**演示流程**：
1. 進入「家庭管理」
2. 展示家庭成員列表（預先設置好主人/工人角色）
3. 展示邀請碼分享功能
4. 進入工人模式（或展示工人模式截圖）
5. 大字體、簡化操作、雙語界面

**預先準備**：
- 家庭管理頁面預先建立測試家庭
- 添加 2–3 個測試成員（主人、工人）
- 工人模式界面截圖/錄影作為後備

### 場景四：採購清單 + HKTVmall（1 分鐘）
**演示流程**：
1. 進入「採購」頁面
2. 展示自動生成的購物清單
3. 勾選已買項目
4. 點擊「買」按鈕，跳轉 HKTVmall 搜索

**預先準備**：
- 排餐計劃預先設置好，自動生成購物清單
- HKTVmall 搜索功能正常運行

### 總結（30 秒）
> 「Kindcipe 唔只是一隻食譜 App——係香港家庭嘅晚餐作業系統。由 IG 匯入、AI 排餐、家庭共享到工人模式，一站式解決『今晚食咩』嘅煩惱。我哋相信科技可以連結家人，而唔係疏遠。」

**上傳位置**：

- Pitch Deck 中可嵌入 QR Code 或連結

- [ ] 網絡測試：確保 Mac 和手机在同一 WiFi
- [ ] 準備後備方案：截圖 + 預錄短片

### Demo 當日

- [ ] 提前 30 分鐘到達會場
- [ ] 測試投影/屏幕連接
- [ ] 關閉通知和來電
- [ ] 開啟飛行模式但保留 WiFi
- [ ] 關閉自動鎖屏（設置 → 顯示 → 自動鎖屏 = 永不）
- [ ] 準備 HDMI / Lightning 轉接線
- [ ] 攜帶充電線

### 常見問題應對

| 問題 | 應對 |
|---|---|
| 網絡不穩 | 使用預先載入的數據，避免即時 API 調用 |
| App 崩潰 | 立即切換到預錄短片或截圖 |
| 電池沒電 | 攜帶行動電源 |
| 評審要求特定功能 | 預備截圖 + 解釋「將喺 CCMF 資助期內完成」 |

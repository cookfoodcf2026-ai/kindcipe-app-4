## Phase 2：Beta 測試與迭代（第 3–4 月，2027-04 至 2027-05）

### 目標
招募 20–30 個香港家庭進行 Beta 測試，完成工人模式第一版

### 關鍵任務

| 任務 | 負責人 | 截止日期 | 成功指標 |
|---|---|---|---|
| 招募 20–30 個香港家庭 Beta 測試 | 開發者 | 2027-04-15 | 完成 25 個家庭招募 |
| 發放 Beta 邀請碼 + 使用指引 | 開發者 | 2027-04-20 | 所有測試者完成安裝 |
| 每週收集反饋 + 2 週一次迭代 | 開發者 | 持續 | 3 輪迭代版本 |
| 完成工人模式第一版 | 開發者 | 2027-05-15 | 大字體 + 雙語 + 簡化操作 |
| 用戶訪談（深度訪談 5–8 個家庭）| 開發者 | 2027-05-20 | 訪談記錄 + 洞察文檔 |
| 數據分析（使用頻率、功能偏好）| 開發者 | 2027-05-25 | 分析報告 |
| 提交中期報告 | 開發者 | 2027-05-31 | 通過數碼港審批 |

### Beta 測試反饋問卷（核心問題）

1. 你每日使用 Kindcipe 幾多次？
2. 最常用功能係邊個？
3. AI 廣東話排餐準確度如何？
4. 工人模式（如有）是否容易使用？
5. 會推薦俾朋友嗎？（NPS）
6. 最多唔滿意嘅地方？

### 預算運用（Phase 2）
- Beta 測試獎勵（超市禮券）：HK$8,000
- 市場驗證推廣（FB/IG）：HK$10,000
- 美食攝影/內容製作：HK$15,000
- 使用撥款：HK$45,000（中期撥款，部分用於 Phase 3 預留）

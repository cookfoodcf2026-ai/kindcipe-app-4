## 2. 問題陳述

### 2.1 香港家庭每日面對的核心痛點

**決策疲勞**
- 香港家庭平均每晚花 **30–60 分鐘** 諗食咩、搵食譜、記材料
- 媽媽/煮食決策者放工後精神已透支，再要處理煮食决策造成家庭壓力

**溝通斷層**
- 香港約 **35 萬名外傭** 負責家庭煮食，但語言障礙導致：
  - 食譜步驟難以準確傳達
  - 買餸時唔清楚要買咩、買幾多
  - 僱主要不斷重複解釋，影響僱主-工人關係

**情感連結流失**
- 一家人各睇各手機，冇人提議食咩
- 煮食决策变成另一種家庭摩擦點
- 根據香港家庭關注組調查，**「今晚食咩」係香港家庭最常見爭拗源頭之一**

**時間機會成本**
- 每晚 1 小時諗食譜 = 每年 **365 小時**
- 可以係運動、進修、陪仔女、或者單純休息的時間

**工人飲食管理盲點**
- 外傭日日煮，但僱主唔知食咩料、油鹽用咗幾多
- 缺乏透明度，影響家庭健康管理

### 2.2 市場數據

| 指標 | 數據 |
|---|---|
| 香港家庭住戶數目 | 約 120 萬戶 |
| 外傭人數 | 約 35 萬人（服務香港家庭） |
| 智能手機滲透率 | 約 92% |
| 家庭主婦/煮食决策者族群 | 估計 40–50 萬人 |
| 目標 TAM | 香港 120 萬家庭住戶 |
| 可觸及 SAM | 有智能手機、聘有或沒有外傭的家庭 |
| 初期目標 SOM | 20–30 個 Beta 家庭 / 100 名高黏性種子用戶 |

## 3. 解決方案

### 3.1 產品定位

**「一站式平台由決定食譜、營養價值，一鍵生成食材清單；係 social media 見到中意既食譜直接 save 低。」**

Kindcipe 係香港家庭嘅晚餐作業系統：

| 功能 | 對應痛點 | 用戶價值 |
|---|---|---|
| **IG/YouTube 食譜一鍵匯入** | 決策疲勞 | 「見到中意即 save，唔使再記」 |
| **AI 廣東話排餐＋營養分析** | 決策疲勞 | 「話我知今晚食咩，仲要健康」 |
| **自動購物清單＋格價** | 溝通斷層 | 「一鍵出清單，工人照住買」 |
| **家庭群組＋審批機制** | 情感連結 | 「阿仔提議食咩，工人確認煮」 |
| **工人雙語模式（大字體）** | 語言障礙 | 「姐姐自己睇得明，唔使逐句翻譯」 |

### 3.2 核心技術差異化

1. **廣東話 AI 助手**：市場上絕大多數食譜 App 只支援普通話/英文，Kindcipe 專為香港家庭打造廣東話自然語言交互
2. **AI 食譜解析**：從 Instagram、YouTube、小紅書、TikTok 連結自動提取食材和步驟，唔使手動輸入
3. **截圖識別**：對住食譜截圖，AI 自動辨識內容並轉換為結構化數據
4. **家庭協作架構**：QR Code 邀請、角色權限（主人/工人）、即時共享
5. **HKTVmall 整合**：採購清單一鍵跳轉 HKTVmall，直接對接香港本地購物習慣

## 4. 營運模式

### 4.1 三層收入模型

| 收入層 | 內容 | 價格 | 預期佔比 |
|---|---|---|---|
| **Freemium 訂閱** | 基礎功能免費；AI 高級功能（ personalised 營養建議、AI 每周餐單規劃）| HK$38/月（早鳥 HK$30） | 60% |
| **HKTVmall 分潤** | 從 App 導流至 HKTVmall 產生的訂單佣金 | 成交額 2–5% | 25% |
| **工人增值服務** | 工人模式高级功能（多語言食譜朗讀、採購照片上傳驗證） | HK$50/月 | 15% |

### 4.2 定價策略

- **個人免費版**： unlimited 食譜儲存、基本排餐、採購清單
- **個人早鳥版**：HK$30/月 — 限時內測價，AI 廣東話助手、personalised 營養分析、无限 AI 生成
- **個人標準版**：HK$38/月 — 正式價，完整 AI 廣東話助手、personalised 營養分析、无限 AI 生成
- **家庭方案**：HK$50/月 — 5 個成員、共享所有功能
- **工人模式**：集成喺家庭方案內；獨立增值服務 HK$50/月

> **定義：早鳥版同標準版功能完全一致，只係價錢與優惠期不同。**

### 4.3 市場進入策略

**Phase 1（CCMF 資助期）**：香港本地 Beta 驗證
- 目標：招募 20–30 個香港家庭進行內測，累積 100 名高黏性種子用戶
- 渠道：Facebook 香港媽媽群、親友推薦、IG/Threads 內容引流
- 合作：先以家庭試點和真實回饋為主，不預設大量付費投放

**Phase 2（2027 下半年）**：產品打磨與口碑驗證
- 完成 3 輪迭代，優先提升匯入、排餐、購物清單、工人模式體驗
- 累積真實用戶故事、示範案例和可公開見證
- 以內測數據調整付費轉換與內容方向

**Phase 3（2028+）**：正式公開上線與區域擴展
- 以經實證嘅產品數據申請後續資助或擴張資源
- 再逐步接觸超市 / 導購 / 東南亞市場拓展
